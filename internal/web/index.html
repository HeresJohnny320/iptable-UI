WireGuard VPS setup

On the home peer, generate a key with umask 077; wg genkey | tee privatekey | wg pubkey > publickey, then paste its public key below. Existing configs are never overwritten, and creating the file does not start the tunnel.

Edit an existing interface

Loads one [Interface] and one [Peer] from the VPS config. The server private key is never shown or changed.

Backups

Your rules and theme are backed up when iptable-ui starts and every 5 minutes while something changed. Restore replaces every rule and the theme with the backup and applies them to the firewall right away. The current state is backed up first, so a restore can be undone.

Saved in …. Download them from there with WinSCP, FileZilla or scp, or with the Download buttons below.
